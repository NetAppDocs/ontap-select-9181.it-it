= Distribuisci un'istanza di valutazione di 90 giorni di un cluster ONTAP Select
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
È possibile implementare un'istanza di valutazione di 90 giorni di un cluster ONTAP Select, con dimensioni che vanno da un cluster a nodo singolo fino a 99 nodi, utilizzando un modello OVF su VMware ESXi. È possibile scaricare una licenza di valutazione se si è un cliente esistente o nuovo. Ad esempio, si è già clienti e si desidera provare una nuova configurazione prima di acquistare una licenza.

.Informazioni su questa attività
* Non è necessario ottenere un numero di serie o una licenza di capacità di archiviazione da NetApp.
* È possibile allocare per i dati utente la stessa quantità di storage prevista per una licenza acquistata.
* È possibile utilizzare solo un account vCenter per distribuire il modello OVF. L'installazione diretta su un host ESXi non è attualmente supportata.
* È necessario installare il modello OVF (contenuto in un file OVA) utilizzando il vSphere standalone client o il vSphere web client (l'unica opzione per ESXi 8.0 e versioni successive). Non si utilizza l'utilità di amministrazione ONTAP Select Deploy.




[[step-1-prepare-the-ontap-select-cluster-host]]
== Passaggio 1: Preparare l'host del cluster ONTAP Select

Utilizzare i seguenti requisiti per preparare l'host ESXi su cui è distribuito il cluster ONTAP Select. La descrizione della piattaforma si basa sulla configurazione di tipo istanza standard o small con storage ad accesso diretto (DAS) locale formattato utilizzando il file system VMFS-5 o VMFS-6.

[[step-2-deploy-a-single-node-ontap-select-cluster-using-an-ovf-template]]
== Passaggio 2: Distribuisci un cluster a nodo singolo ONTAP Select utilizzando un modello OVF

Completare i seguenti passaggi su un server host ESXi a 64 bit supportato.

.Passaggi
. Accedere alla pagina del Programma Prodotti di Valutazione di NetApp e selezionare *ONTAP Select* per scaricare il template OVF di ONTAP Select sulla propria workstation locale.
. Sign in al client web vSphere di VMware utilizzando un account con privilegi amministrativi.
. Seleziona l'host utilizzando una delle seguenti opzioni:
+
** Seleziona *File* > *Distribuisci modello OVF*.
** Seleziona *Datacenter*. Quindi fai clic con il pulsante destro del mouse e seleziona *Distribuisci modello OVF*.


. Seleziona il file OVA sorgente ONTAP Select sulla tua workstation locale, quindi seleziona *Avanti*.
. Esamina i dettagli del modello OVF e seleziona *Avanti*.
. Esamina i dettagli del Contratto di Licenza con l'Utente Finale (EULA) e seleziona *Accetta*. Quindi seleziona *Avanti*.
. Digita il nome della nuova macchina virtuale e seleziona *Avanti*.
. Se sono disponibili più archivi dati, seleziona l'archivio dati e seleziona *Avanti*.
. Seleziona *Thick Provision Lazy Zeroed*, quindi seleziona *Avanti*.
. Selezionare le reti dati e di gestione, quindi selezionare *Avanti*.
. Nella pagina *Proprietà*, inserisci tutti i valori richiesti e seleziona *Avanti*.
. Esamina i dettagli di distribuzione e seleziona *Accendi dopo la distribuzione*.
. Seleziona *Fine* per avviare il processo di distribuzione.
. Dopo che il cluster ONTAP Select è stato distribuito, è possibile configurare il cluster utilizzando System Manager o l'interfaccia CLI. È necessario assegnare il disco utilizzando l'operazione standard ONTAP *disk assign*.
