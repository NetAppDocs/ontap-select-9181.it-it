È necessario definire un account server vCenter e associarlo a un ruolo che contenga i privilegi amministrativi necessari.


NOTE: È inoltre necessario il fully qualified domain name o l'indirizzo IP del vCenter server che gestisce gli host hypervisor ESXi su cui ONTAP Select è distribuito.
