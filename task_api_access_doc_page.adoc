= Accedi alla pagina della documentazione di ONTAP Select Deploy
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
È necessario accedere alla pagina della documentazione online di ONTAP Select Deploy per visualizzare la documentazione API e per effettuare manualmente una chiamata API.

.Prima di iniziare
Devi possedere quanto segue:

* Indirizzo IP o domain name della macchina virtuale ONTAP Select Deploy
* Nome utente e password dell'amministratore


.Passaggi
. Digita l'URL nel tuo browser e premi *Invio*:
+
`\https://<ip_address>/api/ui`

. Sign in utilizzando il nome utente e la password dell'amministratore.


.Risultato
La pagina web della documentazione di Deploy viene visualizzata con le chiamate organizzate per categoria in fondo alla pagina.
