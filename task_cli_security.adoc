= Modificare la password dell'amministratore di Deploy

È possibile modificare la password dell'account amministratore della macchina virtuale Deploy, se necessario, tramite l'interfaccia a riga di comando.

.Passaggi
. Sign in alla CLI dell'utilità Deploy utilizzando l'account amministratore.
. Cambia la password:
`password modify`
. Rispondi a tutte le richieste in modo appropriato per il tuo ambiente.
